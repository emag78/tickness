# Tickness 🧠📋

Clear your mind. Organize what matters.

Tickness is a modern productivity app designed to help you manage tasks, thoughts and daily planning in a simple, focused and stress-free way.

Built around clarity and mental lightness, Tickness combines personal organization with realtime multi-device synchronization, allowing you to share selected tasks and categories across devices through secure shared channels.

---

## 🚀 Main Features

- ✅ Task management with priorities, planning and completion tracking
- 📅 Simple and intuitive calendar view
- 🎯 Focus on daily activities and mental clarity
- 🧠 Designed to reduce overload and help you stay organized
- 🔄 Realtime synchronization between multiple devices
- 🔗 Shared channels with invitation links and QR Code pairing
- 📂 Share entire task categories or single tasks
- 📱 Automatic synchronization recovery after reconnect or app restart
- 🌙 Clean and lightweight interface focused on usability

---

## 🔄 Realtime Synchronization

Tickness introduces a modern synchronization system based on shared channels.

With Tickness Sync you can:
- connect multiple devices together
- invite another device via link or QR Code
- share selected categories or individual tasks
- receive realtime updates automatically across connected devices

The synchronization system is currently in active beta development.
